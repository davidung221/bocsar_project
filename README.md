Monthly criminal incidents in NSW dataset:
This datataset contains monthly data on all criminal incidents in NSW.
Date range: 1995/01 - 2026/03
Offence_categories: 21
Subcategories: 49
Number of incidents: 21,194,009


Monthly criminal incidents in NSW by suburb dataset:
Same dataset as the first one, but grouped by suburbs.

# Census Data Preparation

* Extracted relevant variables from multiple 2021 Australian Bureau of Statistics (ABS) Census datasets.
* Used the accompanying Census metadata and table guides to interpret variable and column definitions accurately.
* Combined the extracted data into a single suburb-level dataset using Excel, linked by Suburbs and Localities (SAL) codes.
* Where required, used Excel `SUM()` functions to combine corresponding male and female counts into total population figures.
* All Census data used in this analysis is sourced from official 2021 ABS Census datasets.
